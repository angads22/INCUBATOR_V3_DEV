Getting around

  • Home: live temperature and humidity, the incubation-day ring, alerts, quick actions and recent events. Readings refresh by themselves — the "Updated Xs ago" note shows how fresh they are.
  • Controls: lock, door, egg turner, camera, candling light and the alarm test. Actions that affect the eggs ask for confirmation first.
  • Status: hardware link health, sensor state, alarms and what each output is doing right now.
  • Help: this page.
  • Menu (the ● button, top right): Settings, Network settings, Vision lab, Setup / change Wi-Fi, and Logout.

On a phone the four main tabs sit at the bottom of the screen. Use your browser's Add to Home Screen to open the incubator like an app.

The setup button

  • Hold {{ _hold }} seconds → setup mode. The buzzer gives one medium beep, the incubator starts its own open Wi-Fi {{ _ap_prefix }}-XXXX, and the setup page opens by itself when you join it. Use this to change Wi-Fi, to reset a forgotten password, or if the incubator ever becomes unreachable.
  • Hold {{ _reset_hold }} seconds → factory reset. After {{ _reset_hold }} seconds the buzzer gives 3 rapid beeps (reset armed); letting go then wipes the name, login, Wi-Fi and settings and restarts in setup mode with 1 long beep. Keep holding past {{ _hold }} s only if you really mean it.
  • Nothing happens for short presses, so an accidental tap is harmless.

Finding your incubator's address

  • By name: http://<name>.local:8000 — the name is shown in Settings → Device (it looks like incubator-ab12). Works on iPhone, Mac, Windows and most Android phones.
  • From your router: open your Wi-Fi router's app or device list and look for the incubator's name; it also shows the IP address.
  • By IP address: http://192.168.x.x:8000 — the current addresses are listed in Settings → Device. Use this if .local names don't open on your Android phone.
  • In setup mode: join {{ _ap_prefix }}-XXXX and open http://{{ _ap_ip }}:8000 if the setup page doesn't appear by itself.

Updates are automatic

  • While it has internet access, the incubator checks for a new release about every 15 minutes and installs it by itself. A short popup on Home links to the release notes.
  • Updates never interrupt heating: the control loop keeps running and a failed update rolls back on its own.
  • The current version is shown at the bottom of Home and in Status.

Troubleshooting: Wi-Fi

  • Change networks: menu → Setup / change Wi-Fi → Start setup mode, then join {{ _ap_prefix }}-XXXX on your phone and pick the new network. Or use Settings → Network to switch directly while you're on the same Wi-Fi.
  • Join failed: the buzzer gives one long beep and the LED flashes SOS; the setup Wi-Fi comes back by itself. Reconnect to it — the wizard asks only for the Wi-Fi again (usually it's the password).
  • Unreachable: hold the setup button for {{ _hold }} seconds and join the setup Wi-Fi, or check the address list above.
  • After switching networks, your phone may still be on the old network — join the new one and reload the page.

Troubleshooting: sensor & alarm

  • Sensor offline: check the sensor wiring{% if dht_pin is defined and dht_pin %} (data pin {{ dht_pin }}){% endif %} and that it is firmly seated. Home keeps showing the last good reading with its timestamp — never fake values — and the heater stays off while the sensor is in doubt.
  • Alarm sounding: the banner on Home says why. Press Silence alarm to quiet the buzzer — the alert stays visible until the cause clears.
  • Too many alerts: widen the alert tolerances in Settings, or untick "Alarm enabled" to disable the buzzer entirely (alerts still appear on screen).
  • Test it works: use Controls → Test alarm for a short chirp.

Candling eggs

  • Open Controls and press Candle ON to light the candling LED, then tap each egg on the tray to note what you see. Press Capture for a photo.
  • The Vision lab (menu) runs the camera through the local model to estimate how far along each egg is and tracks development over time.
  • Remember to press Candle OFF when you finish.

Forgot your password?

  • Hold the device's setup button for {{ _hold }} seconds (the buzzer beeps when it registers).
  • Open Reset password and enter your username or email with a new password.
  • This works only while standing at the device — it is the proof that you own it.
