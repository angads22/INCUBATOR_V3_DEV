Step 1 of 2 · Wi-Fi

Change Wi-Fi / run setup again

To move to a different Wi-Fi network, your incubator switches to its own setup Wi-Fi {{ ap_ssid | default('Incubator') }} for a few minutes. This page stops responding while it does — that's expected.

  1. Tap Start setup mode below (or hold the setup button on the device for 4 seconds).
  2. On your phone, join the Wi-Fi network {{ ap_ssid | default('Incubator') }}{% if ap_password %} (password {{ ap_password }}){% else %} — it's open, no password{% endif %}.
  3. The setup page opens by itself. Pick the new Wi-Fi and you're done.
